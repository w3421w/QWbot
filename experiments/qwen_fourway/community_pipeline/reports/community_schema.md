# 统一结构与边界

见 `community_schema.json`。`platform` 是来源，`domain/topics/subtopics` 是多标签候选分类。分类证据、置信度、版本与人工覆盖另存。`message_id` 由平台、真实视频/笔记/讨论串作用域和原始 ID 构成；跨平台及跨帖不冲突。`speaker_id` 对原始作者 ID 做确定性 SHA-256 短摘要，作用域为平台与来源串；没有作者 ID 时为 null，不从昵称猜测。当前纯摘要适合审核隔离；真实大规模导入应使用受控秘密盐，以防低熵 ID 枚举，盐不能写入导出物。

`parent_comment_id` 和 `root_comment_id` 仅由原始导出字段产生；父节点缺席时保留 ID 并加 `parent_out_of_scope`。不从相邻顺序推断回复。弹幕与直播聊天分别标记类型，不作为评论树。`source_group_id` 基于真实视频/笔记/串 ID，同源组不可跨技术 split。未提供时间戳、视频 ID、许可时保留 null；若评论没有必要来源 ID 则解析失败。真实与 synthetic fixture 明确区分。所有候选均不可训练，也不生成问答。

隐私检测只能发现一部分模式；审核 CSV 对号码、邮箱、私址、私人账号和身份线索脱敏，对中之人身份线索整条隔离。审核时仍应人工检查文本中的昵称、引述、链接及其他非模式化身份信息。审核 CSV 只给源文件名，不给 URL。
