# 数据流水线

## 目标

QWbot V2 Alpha 数据流水线把候选群聊整理为 Qwen 消息格式，用于 LoRA/SFT。核心原则是真实 QQ 群行为优先，人工场景用于补足覆盖面，抗吧/meme 只作为辅助风格信号。

## 数据来源

1. 真实 QQ 群聊天：提供实际的多人上下文、回复时机和口语表达。
2. 人工增强场景：补充低频场景、多人切换话题、认真求助等行为。
3. gold 审核数据：提供经过人工筛选或修订的高质量样本。

所有真实数据应在合法授权、用途明确和隐私保护的前提下处理。原始聊天、用户映射和群映射不得进入公开仓库。

## 处理流程

```text
私有原始/增强数据
        |
        v
SFT JSONL + 元数据 sidecar
        |
        v
结构检查 -> 质量过滤 -> pair 去重
        |
        v
按同源上下文分组切分
        |
        +--> train: 1350
        |
        +--> validation: 150
        |
        +--> 聚合统计报告
```

`scripts/prepare_qwbot_v2_alpha_dataset.py` 要求每条 SFT 记录严格包含 `system`、`user`、`assistant` 三条消息。元数据 sidecar 按行与 SFT 输入对应，用于同源分组；脚本还会合并相同上下文指纹，降低训练集与验证集之间的泄漏风险。

## 发布边界

公开仓库仅保留：

- 经过隐私清理的聚合统计报告。
- 5 条纯虚构格式样例。
- 数据处理脚本与说明文档。

不公开完整 train/validation JSONL、原始 `messages.csv`、sidecar 元数据、真实聊天预览或任何可追溯到群和用户的标识。每次发布前应同时检查工作区、暂存区和 Git 历史。
